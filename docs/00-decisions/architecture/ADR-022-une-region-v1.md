# ADR-022: Une région V1

- Status: Accepted
- Date: 2026-08-01
- Source: WARIBA System Architecture v1.0 §130 (ADR-022), scaffolded during Prompt 01 (Repository Foundation)

## Context

Le budget et la complexité d'une architecture multi-région ne sont pas justifiés pour une bêta de 10 à 25 testeurs.

## Decision

Une seule région primaire, choisie pour la latence Côte d'Ivoire et la disponibilité des providers.

## Consequences

Pas de multi-région prématurée (System Architecture §81).
