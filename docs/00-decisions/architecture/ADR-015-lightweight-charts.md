# ADR-015: Lightweight Charts

- Status: Accepted
- Date: 2026-08-01
- Source: WARIBA System Architecture v1.0 §130 (ADR-015), scaffolded during Prompt 01 (Repository Foundation)

## Context

WARIBA veut un terminal propriétaire, pas une dépendance à une licence commerciale de charting.

## Decision

Lightweight Charts (TradingView) sert de librairie de graphique, alimentée par un adapter de données propre à WARIBA.

## Consequences

Pas de dépendance à TradingView Charting Library sans licence (Engineering Constitution §4.8).
